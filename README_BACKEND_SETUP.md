# VulnTrack v2 backend setup

This document is retained as a compatibility pointer for earlier setup links. The v2 backend uses Flask, SQLite, JWT authentication, Semgrep, optional dependency audits, and optional AI remediation.

Follow [the current backend setup](backend/README.md) for Windows PowerShell installation, `.env` configuration, database separation, API routes, and tests. The v2 API defaults to port `5001`; the frontend defaults to `5174`.
